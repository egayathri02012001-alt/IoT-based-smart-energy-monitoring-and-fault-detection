# ⚡ IoT-Based Smart Energy Monitoring and Fault Detection for MSME Industries

## 📌 Overview

This project develops an IoT-based system for monitoring electrical energy consumption and detecting electrical faults in real time.

The system collects electrical parameters using sensors, processes the data using a microcontroller, and sends the information to an IoT platform for remote monitoring.

## ⚠️ Fault Detection

The system can identify abnormal operating conditions such as:

- Overcurrent
- Overvoltage
- Undervoltage
- Excessive temperature
- Abnormal power consumption

When an abnormal condition is detected, the system generates an alert and can activate a relay to disconnect the load depending on the protection design.

## 📐 Basic Electrical Calculations

### Power

P = V × I

Where:

P = Power in watts  
V = Voltage in volts  
I = Current in amperes

### Energy

Energy = Power × Time

For practical energy monitoring:

Energy (kWh) = Power (kW) × Time (hours)
